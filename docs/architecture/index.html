Agent

  • Serves the web app and answers "where should I play?"
  • Keeps a room on one server, spilling onto another only when it gets busy
  • Hands out a signed ticket (valid 30 s) and gives every player a room-unique id
  • Watches load every second and asks busy servers to move some players
  • Only one agent today: if it stops, nobody new can join

Game Server

  • Holds each room's players and the map's walls
  • Checks every move: not too fast, not into a wall
  • Sends each room an update 20 times a second, only for players who moved
  • One call reaches everyone in a room (Bun pub/sub)

Invariant 01

The server is the referee

Your screen moves you right away, but every position is checked against walking speed and walls. A move that does not add up is corrected back.

Invariant 02

Only what changed is sent

Twenty times a second a room sends just the players who moved, packed in 7 bytes each. People standing still cost nothing.

Invariant 03

No ticket, no entry

A game server only accepts a connection that carries a ticket the agent signed for that exact server and room, used within 30 seconds.
